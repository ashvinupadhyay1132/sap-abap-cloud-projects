# SAP ABAP Cloud Learning Portfolio 🚀

Welcome to my **SAP ABAP Cloud & Modern OO-ABAP** learning repository. 
This repository contains enterprise-level OO-ABAP programs written and tested on **SAP BTP (Business Technology Platform) ABAP Environment**.

---

## 🛠️ Tech Stack & Key Concepts
- **Language:** ABAP / ABAP Cloud (7.5+ Syntax)
- **Framework:** Object-Oriented ABAP (OO-ABAP)
- **Platform:** SAP BTP ABAP Environment / Eclipse ADT
- **Key Concepts Covered:**
  - Classes, Objects & Interfaces (`if_oo_adt_classrun`)
  - Inline Declarations & Type Inference (`DATA(...)`, `VALUE #(...)`, `COND #(...)`)
  - Constructors & Method Signatures (`IMPORTING`, `EXPORTING`, `CHANGING`, `RETURNING`)
  - Object References & Arrow Operator (`->`, `->*`)
  - Internal Tables & Expression Iterations (`LOOP AT REFERENCE INTO`)

---

## 📂 Project Showcase

### 1. Enterprise Sales Order Discount Engine
- **File:** [`zcl_order_processor.abap`](./zcl_order_processor.abap)
- **Domain:** Sales & Distribution (SD) / E-Commerce
- **Description:** Real-time discount engine that validates minimum order limits (MOQ) for Regular & VIP customers, calculates tiered discounts, and computes total net revenue.

### 2. HR Bonus Calculation Engine
- **File:** [`zcl_hr_bonus_calc.abap`](./zcl_hr_bonus_calc.abap)
- **Domain:** Human Resources (HR)
- **Description:** Evaluates employee performance ratings (A, B, C) and experience years to dynamically allocate bonus percentages and calculate final year-end bonus amounts.
